# Render

Inspect Render services, deploys and logs. Use for deployment status and debugging failed builds.

- **Category** — Cloud & DevOps
- **Transport** — stdio
- **Auth** — apiKey (read)
- **Type** — Connector (MCP server: callable tools)

## What this is

A [Pocket Connector](https://usepocket.net/connectors): an MCP server exposing
tools an agent can call. A Connector provides *capability*; a Skill provides the
*knowledge* of how to use it well. Many are best installed as a pair.

## Tools

- `list_services` — Lists services with type and status.
- `list_deploys` — Lists deploys for a service.
- `get_logs` — Returns recent logs for a service.

See [TOOLS.md](./TOOLS.md) for parameters.

## Install

Pocket runs the server for you. To run it directly:

```bash
npx -y render-mcp-server
```

Requires a Render API key.
