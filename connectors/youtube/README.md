# YouTube

Search YouTube and read video transcripts. Use for extracting content from talks and tutorials.

- **Category** — Research & Knowledge
- **Transport** — stdio
- **Auth** — apiKey (read)
- **Type** — Connector (MCP server: callable tools)

## What this is

A [Pocket Connector](https://usepocket.net/connectors): an MCP server exposing
tools an agent can call. A Connector provides *capability*; a Skill provides the
*knowledge* of how to use it well. Many are best installed as a pair.

## Tools

- `search_videos` — Searches for videos by query.
- `get_transcript` — Returns a video's transcript.
- `get_video_details` — Returns a video's title, channel and statistics.

See [TOOLS.md](./TOOLS.md) for parameters.

## Install

Pocket runs the server for you. To run it directly:

```bash
npx -y youtube-mcp-server
```

Requires a YouTube Data API key for search; transcripts may work without one.
