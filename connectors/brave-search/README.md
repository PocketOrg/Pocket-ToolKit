# Brave Search

Search the web with Brave's independent index. Use for privacy-respecting search with structured results.

- **Category** — Research & Knowledge
- **Transport** — stdio
- **Auth** — apiKey (read)
- **Type** — Connector (MCP server: callable tools)

## What this is

A [Pocket Connector](https://usepocket.net/connectors): an MCP server exposing
tools an agent can call. A Connector provides *capability*; a Skill provides the
*knowledge* of how to use it well. Many are best installed as a pair.

## Tools

- `brave_web_search` — Searches the web and returns ranked results.
- `brave_news_search` — Searches recent news.

See [TOOLS.md](./TOOLS.md) for parameters.

## Install

Pocket runs the server for you. To run it directly:

```bash
npx -y @brave/brave-search-mcp-server
```

Requires a Brave Search API key. A free tier is available.
