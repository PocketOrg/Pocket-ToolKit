# Typeform

Create forms and read responses. Use for surveys and structured intake where the answers must be analysed.

- **Category** — Research & Knowledge
- **Transport** — stdio
- **Auth** — apiKey (read, write)
- **Type** — Connector (MCP server: callable tools)

## What this is

A [Pocket Connector](https://usepocket.net/connectors): an MCP server exposing
tools an agent can call. A Connector provides *capability*; a Skill provides the
*knowledge* of how to use it well. Many are best installed as a pair.

## Tools

- `list_forms` — Lists forms in the account.
- `get_responses` — Reads responses for a form.
- `create_form` — Creates a form from a field definition.

See [TOOLS.md](./TOOLS.md) for parameters.

## Install

Pocket runs the server for you. To run it directly:

```bash
npx -y typeform-mcp-server
```

Requires a Typeform personal access token with form and response scopes.
