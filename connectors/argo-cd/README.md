# Argo CD

Inspect Argo CD applications and sync status. Use to check what is deployed and why a sync failed.

- **Category** — Cloud & DevOps
- **Transport** — stdio
- **Auth** — apiKey (read)
- **Type** — Connector (MCP server: callable tools)

## What this is

A [Pocket Connector](https://usepocket.net/connectors): an MCP server exposing
tools an agent can call. A Connector provides *capability*; a Skill provides the
*knowledge* of how to use it well. Many are best installed as a pair.

## Tools

- `list_applications` — Lists applications with sync and health status.
- `get_application` — Returns an application's resources and last sync result.
- `get_sync_history` — Returns recent sync operations for an application.

See [TOOLS.md](./TOOLS.md) for parameters.

## Install

Pocket runs the server for you. To run it directly:

```bash
npx -y argocd-mcp
```

Requires an Argo CD server URL and auth token.
