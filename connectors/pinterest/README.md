# Pinterest

Search Pinterest images and read board data. Use for visual research and reference gathering.

- **Category** — Design & Creative
- **Transport** — stdio
- **Auth** — apiKey (read)
- **Type** — Connector (MCP server: callable tools)

## What this is

A [Pocket Connector](https://usepocket.net/connectors): an MCP server exposing
tools an agent can call. A Connector provides *capability*; a Skill provides the
*knowledge* of how to use it well. Many are best installed as a pair.

## Tools

- `search_pins` — Searches pins by keyword.
- `list_boards` — Lists the authorised account's boards.

See [TOOLS.md](./TOOLS.md) for parameters.

## Install

Pocket runs the server for you. To run it directly:

```bash
npx -y pinterest-mcp-server
```

Requires a Pinterest app access token. Read-only against the authorised account.
