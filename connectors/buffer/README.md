# Buffer

Queue and read scheduled social posts across connected channels. Use for social scheduling without giving an agent each platform's credentials.

- **Category** — Sales & Marketing
- **Transport** — stdio
- **Auth** — apiKey (read, write)
- **Type** — Connector (MCP server: callable tools)

## What this is

A [Pocket Connector](https://usepocket.net/connectors): an MCP server exposing
tools an agent can call. A Connector provides *capability*; a Skill provides the
*knowledge* of how to use it well. Many are best installed as a pair.

## Tools

- `list_channels` — Lists connected social channels.
- `list_scheduled` — Lists queued posts for a channel.
- `create_post` — Adds a post to a channel's queue.

See [TOOLS.md](./TOOLS.md) for parameters.

## Install

Pocket runs the server for you. To run it directly:

```bash
npx -y buffer-mcp-server
```

Requires a Buffer access token for the channels you want reachable.
