# Snowflake

Query Snowflake warehouses and inspect schemas. Use for analytics and warehouse cost investigation.

- **Category** — Data & Analytics
- **Transport** — stdio
- **Auth** — apiKey (read)
- **Type** — Connector (MCP server: callable tools)

## What this is

A [Pocket Connector](https://usepocket.net/connectors): an MCP server exposing
tools an agent can call. A Connector provides *capability*; a Skill provides the
*knowledge* of how to use it well. Many are best installed as a pair.

## Tools

- `list_databases` — Lists databases and schemas.
- `describe_table` — Returns a table's columns and types.
- `query` — Runs a SELECT query. Consumes credits.

See [TOOLS.md](./TOOLS.md) for parameters.

## Install

Pocket runs the server for you. To run it directly:

```bash
npx -y snowflake-mcp-server
```

Requires account, warehouse, role and credentials. Queries consume warehouse credits.
